# 设计说明

## 目标

应用面向不具备 Python 环境的普通 Windows 用户，发布物必须是一个可直接双击的 x64 EXE，并同时满足图形化管理和长期静默监控。

## 进程模型

单一进程内包含三个部分：

- Tk 主线程：管理界面与事件循环；
- `MonitorThread`：自动登录后台循环（检查、认证、通知、日志维护）；
- 托盘线程：Win32 `Shell_NotifyIconW` 图标与右键菜单。

同一个 EXE 根据参数进入不同模式：

- 无参数：管理界面；
- `--hidden`（旧参数 `--monitor` 作为兼容别名）：隐藏到托盘启动；
- `--first-run`：完成首次安装后的设置界面；
- `--check-once`：执行一次网络检查；
- `--self-test PATH`：执行发布自检并输出 JSON。

关闭界面只是隐藏到系统托盘，自动登录继续运行；托盘菜单“退出”才会结束进程。应用通过命名互斥量保证单实例，重复启动会把已运行实例的主窗口带到前台。计划任务在登录时以 `--hidden` 启动程序，隐藏到托盘工作。

## 自安装

下载的 EXE 首次运行时：

1. 复制自身到 `%LOCALAPPDATA%\Programs\GDUTAutoLogin`；
2. 创建开始菜单快捷方式；
3. 从原 EXE 所在目录迁移旧版数据（如果存在）；
4. 启动已安装位置的 EXE；
5. 创建当前用户的隐藏登录触发计划任务（隐藏到托盘运行界面）。

旧版本使用独立 `--monitor` 计划任务的用户，会在新版首次启动时自动升级为 `--hidden` 任务。

选择用户目录可以避免管理员权限和 UAC 提权。

## 数据模型

### config.json

保存网卡 MAC、网卡名称、探测间隔、认证入口、日志上限和通知设置，不保存密码。

### accounts.json

账号列表直接以 UTF-8 JSON 保存，便于编辑、导入、导出和分享。

### events.db

SQLite 数据库，使用 WAL 模式。日志表包含 UTC 时间、级别和消息。界面显示时转换为本地时间。

维护策略同时考虑：

- 按保留天数删除；
- 按数据库总容量删除最旧记录；
- WAL checkpoint；
- 必要时 VACUUM 回收空间。

### status.json

后台监控写入的轻量状态快照。GUI 每两秒读取一次，无需长期持有数据库连接或建立本地网络服务。

## 网络接口选择

程序读取 `Get-NetAdapter`、`Get-NetConnectionProfile` 和当前无线 SSID，并通过接口索引和物理 MAC 识别网卡。界面只列出当前已连接、启用的物理接口，不限制网卡别名、Windows 网络名称或无线 SSID，因此也支持首次连接时显示为“未知的网络”的有线校园网。

列表优先排列带 `10.x.x.x` 地址的接口，并在首次设置中提醒用户选择 10 网段。用户保存选择后，后台优先使用该物理 MAC 对应的接口；已保存接口不可用时，只在候选明确的情况下切换到唯一已连接接口。

检查请求、登录请求和登录后的复检都通过 `source_address=(selected_ip, 0)` 绑定同一个源 IP，避免其他联网接口影响结果。

当没有明确可用的接口，或最终选定接口尚未取得 `10.x.x.x` 地址时，程序停止本轮操作并静默等待，不会借用其他接口的地址发起探测或认证。

## 并发控制

- 应用使用 Windows Named Mutex 保证单实例，第二实例通过命名事件唤醒已运行实例；
- 网络检查和登录操作使用第二个 Named Mutex，避免手动检查与后台线程同时提交认证请求；
- 配置和状态使用临时文件加原子替换写入；
- SQLite 使用 WAL 和短连接，降低界面与监控线程并发读写冲突。

## 日志安全

- 密码从不写入日志；
- 账号在日志中脱敏；
- 认证响应只记录必要摘要；
- 用户可以在界面搜索和筛选日志；
- 数据默认只保存在当前用户 LocalAppData。

## 发布模型

PyInstaller 使用：

- `--onefile`：单文件发布；
- `--windowed`：不创建控制台窗口；
- Windows 版本资源：显示产品名和版本；
- 构建后自检：在独立空数据目录运行；
- SHA-256：生成 Release 校验文件。

公开发布前还应增加 Authenticode 签名。签名必须在最终 EXE 生成后、计算发布哈希之前完成。

## 界面结构

管理界面只保留四个主页面：概览、账号、日志和设置。连接详情合并到概览，软件更新合并到设置，避免把开发或发布细节暴露给普通用户。
