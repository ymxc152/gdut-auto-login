# 使用说明

## 安装

从项目 [Releases](https://github.com/ymxc152/gdut-auto-login/releases/latest) 下载最新 Windows x64 EXE，双击后程序会自动安装到当前用户目录，不需要管理员权限。

首次设置时：

1. 先连接校园网；
2. 在列表中选择 IPv4 地址为 `10.x.x.x` 的物理网卡；
3. 输入校园网账号和密码；
4. 点击“确认启用”。

程序不要求网卡名称、Windows 网络名称或 Wi-Fi SSID 包含 `GDUT`。有线校园网首次连接时可能显示为“未知的网络”，只要该接口带有 `10.x.x.x` 地址即可选择。
输入密码时可以勾选“显示密码”进行核对。

设置完成后不会再弹出“安装完成”窗口，后台监控会直接启动。
如果取消“登录 Windows 后自动在后台运行”，当前后台仍会启动，但下次登录 Windows 时不会自动启动。

所选接口未连接或尚未取得 10 网段地址时，程序只会静默等待并定时重试，不写入警告日志，也不会发送失败或更新通知。

## 界面

### 概览

显示当前网络状态、后台服务、最近使用的账号、所选接口和最近活动。可以手动“立即检查”或“重新连接”。

### 账号

- 点击“添加账号”添加新账号；
- 双击已有账号或点击“编辑”修改账号；
- 编辑时密码留空表示保留原密码；
- 点击“删除”移除账号。
- 点击“导出账号”生成可分享的 JSON 文件；
- 点击“导入账号”合并备份账号，同名账号会更新密码。

账号和密码以普通 JSON 保存在当前 Windows 用户的数据目录中，不会写入日志。导出文件同样包含明文账号和密码，只应分享给可信的人。

### 日志

可以按时间、级别和关键词查看最近记录，也可以点击“清空日志”删除全部日志。日志默认最多占用 20 MB，超过限制后自动清理最旧记录。

### 设置

可以修改：

- 当前使用的网络接口；
- 网络检查和重试间隔；
- 开机后台运行和失败通知；
- 直接启动、停止或重启后台服务；
- 日志容量与保留时间；
- 自动检查更新。

设置修改后会自动保存并立即生效，不需要点击保存按钮。关闭管理界面不会停止后台监控。
网络接口列表会在启动和进入设置页时自动刷新，只显示当前已连接的物理网卡；断开、禁用和虚拟接口不会显示。列表不限制名称，并会把带 `10.x.x.x` 地址的接口排在前面。

## 多网卡

程序会把检测和登录请求绑定到用户选定接口的 `10.x.x.x` 源 IP。即使其他 Wi-Fi、网线、VPN 或虚拟网卡可以联网，也不会替代所选接口完成检测或登录。

更换网卡、扩展坞或网络后，请到“设置”重新选择网络接口。

## 更新

程序可以在“设置”中检查 GitHub Release。发现新版后，可下载并校验 SHA-256；安装前仍需用户确认。更新失败时会恢复旧版。

当前公开 EXE 没有 Authenticode 证书，Windows 可能显示 SmartScreen“未知发布者”。

## 数据位置

| 路径 | 内容 |
| --- | --- |
| `%LOCALAPPDATA%\Programs\GDUTAutoLogin` | 已安装程序 |
| `%LOCALAPPDATA%\GDUTAutoLogin` | 账号、设置、状态和日志 |

## 卸载

在“设置”底部点击“卸载”。可以选择保留个人数据，方便以后重新安装继续使用。
