# 使用说明

## 安装

从项目 [Releases](https://github.com/ymxc152/gdut-auto-login/releases/latest) 下载最新 Windows x64 EXE，双击后程序会自动安装到当前用户目录，不需要管理员权限。

首次设置时：

1. 先连接名称或 SSID 包含 `GDUT` 的有线或无线网络；
2. 在列表中选择该网络；
3. 输入校园网账号和密码；
4. 点击“完成设置”。

设置完成后不会再弹出“安装完成”窗口，后台监控会直接启动。

## 界面

### 概览

显示当前网络状态、后台服务、最近使用的账号、GDUT 接口和最近活动。可以手动“立即检查”或“重新连接”。

### 账号

- 点击“添加账号”添加新账号；
- 双击已有账号或点击“编辑”修改账号；
- 编辑时密码留空表示保留原密码；
- 点击“删除”移除账号。

密码使用 Windows DPAPI 保存在当前 Windows 用户的数据目录中，不会写入日志。

### 日志

可以按时间、级别和关键词查看最近记录。日志默认最多占用 20 MB，超过限制后自动清理最旧记录。

### 设置

可以修改：

- GDUT 网络接口；
- 网络检查和重试间隔；
- 开机后台运行和失败通知；
- 日志容量与保留时间；
- 自动检查更新。

保存成功后只在页面内短暂显示状态，不会弹出窗口。

## 多网卡

程序会把检测和登录请求绑定到选定 GDUT 接口的源 IP。即使其他 Wi-Fi、网线、VPN 或虚拟网卡可以联网，也不会替代 GDUT 接口完成检测或登录。

更换网卡、扩展坞或网络后，请到“设置”重新选择 GDUT 网络。

## 更新

程序可以在“设置”中检查 GitHub Release。发现新版后，可下载并校验 SHA-256；安装前仍需用户确认。更新失败时会恢复旧版。

当前公开 EXE 没有 Authenticode 证书，Windows 可能显示 SmartScreen“未知发布者”。

## 数据位置

| 路径 | 内容 |
| --- | --- |
| `%LOCALAPPDATA%\Programs\GDUTAutoLogin` | 已安装程序 |
| `%LOCALAPPDATA%\GDUTAutoLogin` | 账号、设置、状态和日志 |

## 卸载

在“设置”底部点击“卸载”。可以选择保留个人数据，方便以后重新安装继续使用。
