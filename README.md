# GDUT 校园网自动登录

适用于 Windows 10/11 的 GDUT 校园网自动连接工具，支持有线和无线网络。

## 下载

前往 [Releases](https://github.com/ymxc152/gdut-auto-login/releases/latest) 下载最新的：

```text
GDUTAutoLogin-版本号-win64.exe
```

只需要一个 EXE，不需要安装 Python，也不需要管理员权限。

## 使用方法

1. 先连接校园网，再双击下载的 EXE。
2. 在首次设置中选择 IPv4 地址为 `10.x.x.x` 的网卡。
3. 输入校园网账号和密码，点击“确认启用”。

有线校园网可能显示为“未知的网络”，这是正常的，按 `10.x.x.x` 地址选择即可。之后程序常驻系统托盘自动检查网络，掉线时自动重新连接；点关闭会隐藏到托盘，托盘右键菜单可以退出。

## 主要功能

- 支持 GDUT 有线和无线网络，不限制网卡名称或网络名称；
- 断网后自动恢复校园网认证；
- 多网卡环境绑定用户选定的网络接口；
- 账号导入、导出和管理；
- 日志查看、筛选和清空；
- 系统托盘常驻，右键菜单可打开、立即检查或退出；
- 开机自动启动并隐藏到托盘运行，不弹出命令行窗口；
- 自动更新。

设置修改后立即生效，不需要保存按钮。
